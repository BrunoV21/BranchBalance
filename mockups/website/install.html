Four short steps

Download, install, and start sharing.

Android may show an extra safety message because BranchBalance is not in the Play Store yet. The wording varies by phone.

  1. 1

    Download the app

    Tap Download for most phones. If your browser asks whether to keep the file, confirm that you want to download BranchBalance.

  2. 2

    Allow this installation

    Open the downloaded file. If Android asks, allow your browser to install this app, then tap Install. You can turn that permission off again afterward.

  3. 3

    Open BranchBalance

    Open the app and continue to GitHub. Sign in with an existing account or create a free one, then approve the one-time connection.

  4. 4

    Create or join a group

    Start a private Trip or Fuel group and invite people you know—or accept an invitation to an existing group.

Only install the copy downloaded from this website

The safety prompt is expected for an app installed outside the Play Store. If the filename or source looks different, cancel and return to this page.

Starting a group?

You will connect BranchBalance once.

GitHub keeps the group private and lets you choose who can join. BranchBalance will explain the requested access before sending you there.

Read the first-group guide

Joining a group?

Your route is shorter.

Install the app, sign in with the GitHub account that was invited, and accept the group invitation. You do not create another integration.

Read the joining guide
