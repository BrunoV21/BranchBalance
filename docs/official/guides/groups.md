# Create or join a group

## Choose the group type

Every group can split expenses and calculate balances. The group type adds planning and spending tools for what you are tracking:

- **Trip** uses start and end dates, a total trip budget, daily spending guidance, and travel-focused insights.
- **Fuel** uses monthly spending limits and fuel details such as litres, unit price, discounts, and station.

The group type cannot be changed after creation because it controls the group’s plan and analytics. If you need another type, [send a group-type feature request](https://github.com/BrunoV21/BranchBalance/issues/new?template=group_type_request.yml). The request is public, so do not include private spending details.

## Create the group

From **Your groups**, tap **Create a group**. Choose Trip or Fuel, enter a name, and select EUR, USD, or GBP. BranchBalance creates the group’s private space and takes you to its overview.

If setup stops part-way through, use the safe retry shown in the app instead of creating the same group again.

## Invite members

Open the group’s **Members** tab and enter the GitHub username of someone you know. They appear as pending until they accept or decline the invitation.

Ask them to install BranchBalance and sign in with the exact GitHub account you invited.

## Join an invited group

Eligible invitations appear below **Create a group** on **Your groups**. Review who invited you and which group you are joining, then tap **Accept** or **Decline**. An accepted group moves into **Active groups**.

If an expected invitation is missing, confirm that you signed in with the invited GitHub account, then refresh **Your groups**.

Read [owners, members, and invitations](../documentation/permissions) for more detail about access.
