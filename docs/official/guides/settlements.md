# Settle what people owe

Open the group’s **Balances** tab to see who owes money and the shortest suggested list of payments. BranchBalance calculates these suggestions from the group’s shared expenses.

## Record money sent

Payments happen outside BranchBalance using cash, bank transfer, or another payment app. After sending money, record the payment in BranchBalance so the group can see that it is waiting for confirmation.

You can add a short shared note, but never include a password, PIN, card security code, recovery code, or access token. Group members can see the note, and Git history may retain an older version after deletion.

## Confirm that it arrived

Only the person receiving the money can confirm it arrived. Until then, the amount is shown as pending so it is not suggested a second time.

After confirmation, everyone sees the updated balances and payment history. If the payment did not happen, delete the pending record and the original suggestion returns when it is still needed.
