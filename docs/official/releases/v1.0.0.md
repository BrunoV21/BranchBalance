# v1.0.0

<!-- release-notes:start -->

[Download BranchBalance v1.0.0 for Android](https://github.com/BrunoV21/BranchBalance/releases/tag/v1.0.0). The release includes the signed `BranchBalance-v1.0.0.apk` and its SHA-256 checksum.

## Highlights

- Create a group as a private `branch-balance-<slug>` repository and invite GitHub users as members.
- Add, edit, and delete dated expenses with equal, full-to-one, or Just me allocation.
- Derive exact balances and a deterministic settlement list from integer minor-unit shares.
- Plan group spending with optional group and category budgets, payment methods, filters, trip dates, and daily guidance.
- Keep legacy expenses valid with explicit Uncategorized and Unspecified presentation.
- Protect edits and deletes with GitHub blob identifiers so concurrent changes are never overwritten silently.

## Platform and data

- Android is the supported platform for this release.
- Group data stays in a private GitHub repository owned by the group creator.
- Reads and writes require a network connection, and one currency is used per group.

## Known constraints

- Settlements cannot yet be recorded as paid.
- Receipt images, percentage splits, currency conversion, and push notifications are not included.
- Groups are currently owned by personal GitHub accounts rather than organizations.
