# v1.1.0

<!-- release-notes:start -->

[Download BranchBalance v1.1.0 for Android](https://github.com/BrunoV21/BranchBalance/releases/tag/v1.1.0). The release includes the signed `BranchBalance-v1.1.0.apk` and its SHA-256 checksum.

## Highlights

- Record settlement payments made outside BranchBalance, reserve pending amounts, let the recipient confirm receipt, and review or delete payment history with optional shared notes.
- Catch up from **Your groups** with an on-device activity inbox, unread indicator, explicit or swipe-to-dismiss actions, and Clear all confirmation.
- Understand budget pace with cumulative tracked spending against a clearly labelled **Even budget pace** reference, without presenting a forecast.
- Explore daily spending, ranked category mix, and Shared versus Just me totals, then drill directly into matching expenses by date, category, or scope.
- Compare each member's Paid and Share values on one scale and keep the expense funding gap distinct from settlement-adjusted net balances.
- Use the same analytics through accessible textual summaries, labelled series, minimum touch targets, light/dark themes, and motion-free charts.
- After inviting a collaborator, see repository-specific guidance asking them to accept at `github.com` and refresh **Your groups**; eligible invitations can also be reviewed in the app when GitHub exposes them to the authenticated GitHub App user token.

## Upgrade notes

- Existing v1.0.0 groups and expenses remain compatible; no repository migration is required.
- `settlements.json` is created only when the first settlement payment is recorded.
- Activity history and read state are stored only on the device and are isolated by signed-in account.
- Analytics are derived locally from the current validated group snapshot and are not persisted to GitHub.

## Platform and data

- Android remains the supported platform, and this build uses Android version code 2 for in-place upgrades from v1.0.0.
- Group expenses, plans, and settlement records stay in the group's private GitHub repository.
- BranchBalance adds no application backend, telemetry pipeline, push service, or background synchronization.

## Known constraints

- GitHub App user tokens may not expose pending private-repository invitations before acceptance. When an invitation is missing in BranchBalance, accept it on GitHub and refresh **Your groups**.
- The activity inbox is a best-effort view of changes observed while the app is open or returns to the foreground; it is not push notification delivery or a complete audit log.
- Even budget pace is a reference based on recorded expenses, not a prediction of final trip spending.
- Receipt images, percentage splits, currency conversion, organization-owned groups, and background/offline writes are not included.
