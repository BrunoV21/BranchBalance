# v1.2.0

<!-- release-notes:start -->

[Download BranchBalance v1.2.0 for Android](https://github.com/BrunoV21/BranchBalance/releases/tag/v1.2.0). The release includes signed APKs for `arm64-v8a` and `armeabi-v7a` devices plus their SHA-256 checksums.

## Highlights

- Start from the camera action beside **Add expense**, then photograph a paper receipt or choose an existing image from Photos.
- Read receipt text entirely on the Android device with bundled PaddleOCR models; receipt images and recognized text are never uploaded for OCR.
- Prefill the normal expense form with a detected merchant, total, and date when confidence is sufficient, and check an explicit receipt currency against the group's currency.
- Review ordinary editable fields before saving, with clear warnings for ambiguous totals, currency mismatches, missing values, and lower-confidence results.
- Retake a receipt or continue with manual entry at any time. Category, payment method, payer, and split remain deliberate user choices.

## Upgrade notes

- Existing groups, expenses, settlements, activity, and analytics remain compatible; no repository migration is required.
- OCR models are bundled in the Android APK, so this release is larger than v1.1.0 and does not download a model after installation.
- Receipt capture, image preparation, OCR, parsing, and review work without a network connection. Saving the confirmed expense still requires GitHub connectivity.
- BranchBalance requests camera or photo-library access only when that input is used; manual expense entry remains available without either permission.

## Platform and data

- Android remains the supported platform, and this build uses Android version code 3 for in-place upgrades from earlier releases.
- Prepared images live only in a bounded application cache and are deleted after handoff, cancellation, or failure; the original photo remains under Android and user control.
- Receipt pixels, OCR blocks, detected values, and confidence data are not attached to the expense or written to the group's GitHub repository.
- Only the final expense fields explicitly reviewed and saved by the member use the existing GitHub-backed expense workflow.

## Known constraints

- OCR accuracy depends on lighting, focus, receipt condition, print quality, and layout. Every detected field must be reviewed before saving.
- The first parser targets common English and Portuguese receipt labels and supports EUR, USD, and GBP currency checks.
- Receipt line items, categories, payment methods, payers, and split choices are not inferred, and BranchBalance does not retain a receipt image with the expense.
- Expo Go cannot run the custom OCR module; receipt scanning requires the packaged Android app or an Expo development build.
