# v1.0.0 Preview

<!-- release-notes:start -->

## Highlights

- Create a group as a private `branch-balance-<slug>` repository and invite GitHub users as members.
- Add, edit, and delete dated expenses with equal, full-to-one, or Just me allocation.
- Derive exact balances and a deterministic settlement list from integer minor-unit shares.
- Follow optional group and category budgets, payment methods, filters, trip dates, and daily spending guidance.
- Keep legacy expenses valid with explicit Uncategorized and Unspecified presentation.
- Protect edits and deletes with GitHub blob identifiers so concurrent changes are never overwritten silently.

## Release gate

The code and automated coverage represent Phase 1 plus the CR-001 spending increment. Before this becomes a stable release, the complete product loop must pass on physical Android devices with two real GitHub accounts.

No stable APK is published yet. This is a development milestone, not a download announcement.

## Known constraints

- Android is the only supported release target.
- Reads and writes require a network connection.
- Groups are owned by personal GitHub accounts.
- One currency is used per group.
- Settlements cannot yet be recorded as paid.
- There are no receipt images, percentage splits, currency conversion, or push notifications.

## For contributors

Read the [testing guide](../reference/testing) for the automated and physical-device gates, and the [product requirements](../reference/PRD) before changing behavior.
