# Sign in for the first time

BranchBalance uses GitHub to keep each group private and decide who can join. You need a free GitHub account, but you do not need to understand repositories or write code.

## Before you begin

- [Install BranchBalance on your Android phone](../install).
- Use an existing GitHub account or [create one for free](https://github.com/signup).
- If you were invited to a group, sign in with the exact GitHub account that received the invitation.

## Connect your account

1. Open BranchBalance and tap **Continue with GitHub**.
2. BranchBalance shows a short code and opens GitHub in your browser.
3. Enter the code if GitHub asks for it, then approve the connection.
4. Return to BranchBalance. The app completes sign-in and opens **Your groups**.

The code is temporary. BranchBalance never asks you for your GitHub password.

## What you are approving

GitHub provides sign-in, private group storage, and group membership. A group creator approves the access needed to create and manage the group’s private space. An invited member approves access so BranchBalance can open groups already shared with them.

BranchBalance stores the sign-in credentials in Android’s protected storage. You can revoke access later from your GitHub settings.

::: tip The short version
GitHub is the private storage and invitation service behind BranchBalance. You can use the app without learning GitHub’s developer tools.
:::
